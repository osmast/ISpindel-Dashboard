# 5. Deliverables and presentation

## Deliverables

All deliverables are due at the final presentation (M4, 12.11.2026).

* **D1 - Concept.** 1 to 2 pages: architecture diagram with the assignment to the levels of the
  automation pyramid, data model, technology choice with justification, assumptions and
  clarifications with the client.
* **D2 - Running system.** System running on the Raspberry Pi with the data of the fermentation
  phase.
* **D3 - Source code.** Including README and configuration file.
* **D4 - Presentation.** 15 minutes plus questions, including a live demo.

## The presentation

The presentation covers four parts:

1. **Concept.** Explain the architecture, the data model and the technology choice.
2. **Live system.** Demonstrate the running system and its main functions in the dashboard.
3. **Interpretation of the data.** Interpret the fermentation of the own beer with reference to the
   brewing process. Compare it with the sketch made at the beginning (lag phase, main
   fermentation, end of fermentation) and show how the dashboard answers the two questions written
   down in the self-study.
4. **Outlook.** Show what would be improved in a next iteration.

> Info from the specification: Should and Could requirements only add value on top of a working
> core system. Focus first on fulfilling all Must requirements.
